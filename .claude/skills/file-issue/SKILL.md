# file-issue

Read AGENTS.md and CLAUDE.md first. Use docs/qa-gate.md for supported checks. Preserve the personal-notes prohibition in every tool and delegation.

Research the current project implementation. Draft a focused title, problem, known
reproduction, expected behavior, scope and verifiable acceptance criteria. Do not invent
results. Use only an explicitly identified repository or verified project remote; if none
exists, prepare a local draft. Creating an issue requires an explicit user instruction;
a draft request is not authorization. Do not default to levy-street/world-of-claudecraft.
