# asset-pipeline

Read AGENTS.md and CLAUDE.md first. Use docs/qa-gate.md for supported checks. Preserve the personal-notes prohibition in every tool and delegation.

Use the image-to-glb workflow at .claude/skills/image-to-glb/SKILL.md for integration.
The upstream Tripo pipeline and its media prerequisites were not imported as a working
product tool. Inspect available tooling before choosing procedural, Blender or external
authoring. Read ASSETS.md and docs/ART_DIRECTION.md. Record provenance, performance budget,
model/rig/clip contract and collider needs. Review exported views, animation loops and the
actual in-game result. Do not copy upstream character rigs or pay for generation implicitly.
A request for a static asset does not authorize new gameplay or new external services.
