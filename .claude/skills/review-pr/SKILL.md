# review-pr

Read AGENTS.md and CLAUDE.md first. Use docs/qa-gate.md for supported checks. Preserve the personal-notes prohibition in every tool and delegation.

Resolve the user-specified repository, base and head. Never default to the WoC repository.
Read the actual diff and surrounding paths, trace correctness, authority, parity,
persistence and tests. Use matching reviewers and supported targeted checks. Confirm
consequential findings with path/line and impact. Return findings and missing evidence.
A review request permits reading and drafting, not submitting reviews, comments or edits.
