# write-game-tooltips

Read AGENTS.md and CLAUDE.md first. Use docs/qa-gate.md for supported checks. Preserve the personal-notes prohibition in every tool and delegation.

Read content records, handlers, resolved values and focused tests. Record targets,
timing, damage/healing, scaling stats, triggers, caps and consumption. Write concise text
from these mechanics, using live resolved values for dynamic numbers. Follow the existing
English catalog/t() seam; never hand-edit generated output or silently promise unimplemented
behavior. Add focused checks for meaningful mechanic/text mismatches and run relevant checks.
