# pr-screenshots

Read AGENTS.md and CLAUDE.md first. Use docs/qa-gate.md for supported checks. Preserve the personal-notes prohibition in every tool and delegation.

Identify the authorized localhost route and requested viewports. Use the browser tooling
available in this session, not a presumed Puppeteer/MCP setup. Do not capture other apps,
personal notes, account history or unrelated tabs. Use matching camera, position, viewport
and workload for before/after; store task images in the project without credentials.
Report when baseline or mobile-device evidence is unavailable. Do not commit, attach to a
remote PR or publish screenshots without authorization.
